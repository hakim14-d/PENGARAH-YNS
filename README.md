# Piala Pengarah Yayasan Negeri Sembilan — Bola Tampar

Dashboard skor langsung, jadual dan kedudukan pasukan.
Venue: RKS Senawang · Mula 9:00 pagi · 1 gelanggang · Terbaik 3 set (15 mata, deuce had 17).

Pengurusan teknikal: Persatuan Bola Tampar Negeri Sembilan (NSVA).

## Cara kemas kini skor
Skor dibaca daripada Google Sheet "Piala Pengarah YNS - Skor Bola Tampar".
Pegawai teknikal hanya perlu isi lajur SET1 A … SET3 B dalam Sheet itu.
Dashboard membaca semula Sheet setiap 15 saat.

Jangan ubah tajuk lajur pada baris pertama Sheet.

## Tetapan
ID Sheet ditetapkan dalam `index.html` (pemboleh ubah `SHEET_ID`).
